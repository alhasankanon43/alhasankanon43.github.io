# Abdullah Al Hasan — Research Scholar Portfolio (Version 3)

## Open locally
Double-click `index.html`. Keep `styles.css` and `profile-photo.jpg` in the same folder.

## Publish for free on GitHub Pages
1. Create a free GitHub account.
2. Create a **public** repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username).
3. Upload `index.html`, `styles.css`, and `profile-photo.jpg` to the repository root and commit.
4. In repository Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
5. Visit https://YOURUSERNAME.github.io after deployment completes.

## Review before publishing
- Verify exact bibliographic titles, author order, journal details, DOIs and acceptance status against your records.
- Confirm the Google Scholar and LinkedIn links and email address.
- Check current degree dates, employment and CGPA.
- Contact phone and physical address are deliberately not published for privacy.
- To add a downloadable CV, place a reviewed PDF file in this folder and add a link to it in the HTML.
- Update or replace the original photo as desired.
